# Test Files

## How These Files Were Created

Each randomized binary file was generated by reading random data from the system's random data source (`/dev/urandom`) and writing exactly the specified number of bytes to a file. For example, `testfile_100K.bin` contains 100,000 bytes of random data.

The SHA256 hash for each file was then calculated by processing the entire file content through the SHA256 cryptographic hashing algorithm, which produces a unique 256-bit fingerprint. This hash can be used to verify the file's integrity—if even a single bit changes, the hash will be completely different.

### Commands Used (Example with 100KB file)

```bash
# Generate a 100KB random binary file
dd if=/dev/urandom of=testfile_100K.bin bs=1 count=100K

# Calculate the SHA256 hash
sha256sum testfile_100K.bin
```

The same approach was applied to all file sizes (200K, 500K, 1M, 2M, 3M, 5M).
